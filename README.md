# Tkinter Multiplication Quiz

A lightweight desktop quiz app built with Python and Tkinter to help improve mental maths and multiplication speed in a clean, distraction-free interface.

## Features

- Custom quiz length – choose how many questions to attempt (defaults to 5 if invalid)
- Live timer – tracks your total time in seconds from start to finish
- Instant feedback – correct answers highlighted in green, incorrect in red
- Keyboard-friendly – use Enter to start, submit answers, and progress through the quiz
- Auto-centred window – opens neatly in the centre of the screen

## Requirements

- Python 3.x
- Tkinter (usually included with Python)
  - On Linux:
    ```bash
    sudo apt-get install python3-tk
    ```

## How to Run

```bash
cd path/to/your/folder
